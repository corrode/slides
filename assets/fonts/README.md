# Vendored fonts

Inter, Bebas Neue, JetBrains Mono, and Merriweather are distributed under the SIL Open Font License 1.1. The license for each of those families is stored beside the font files.

- **Inter 4.1**: `inter-variable.woff2` and `inter-variable-italic.woff2`, from <https://github.com/rsms/inter/releases/tag/v4.1>. See `LICENSE-Inter.txt`.
- **Bebas Neue 2.000**: `bebas-neue-regular.woff2`, from Dharma Type's Bebas Neue repository at commit `46e72cec95ee599f72c0de4a12cfe64828949236`. See `LICENSE-Bebas-Neue.txt`.
- **JetBrains Mono**: `jetbrains-mono-regular.woff2`. See `LICENSE-JetBrains-Mono.txt`.
- **Merriweather v31 Latin**: regular, bold, and italic WOFF2 files. See `LICENSE-Merriweather.txt`.
- **Happy / Happy Headline**: whitelabel cuts of Typejockeys Sorglos Sans, distributed under the owner's private commercial license.
