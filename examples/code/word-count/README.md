# Word-count slide examples

This directory contains the Python and Rust snippets referenced by `examples/intro-to-rust.md`.

Run all checks from the repository root:

```sh
python3 examples/code/word-count/verify.py
```

The verifier executes the working examples, checks the intentionally incomplete or non-compiling Rust steps for their expected failures, and confirms that the slide code fences still reference the intended numbered source files in order.
