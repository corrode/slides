Upload a presentation draft

Save the complete UTF-8 deck as slides.md. Its first H1 supplies the title; keep it nonempty and at most 120 characters. There is no manifest or separate metadata body. Choose the slug in the request URL.

Run this from the directory containing slides.md. Python's standard-library ZIP command puts it at the archive root, without a wrapper parent directory:

python3 -m zipfile -c presentation.zip slides.md
curl --fail-with-body --request POST \
  "$SLIDES_URL/api/v1/presentations/my-talk/bundle" \
  --header "Authorization: Bearer $SLIDES_API_TOKEN" \
  --header "Content-Type: application/zip" \
  --data-binary @presentation.zip

For sibling asset directories, use python3 -m zipfile -c presentation.zip slides.md code images demo. Alternatively, if installed, use zip -r presentation.zip slides.md code images demo with a fresh output ZIP. Include only directories that exist; ZIP the contents, not their parent folder.

The request body is raw ZIP, not JSON or multipart. Creation returns 201 Created; replacing a draft returns 200 OK. The JSON response contains slug, title, files, and bytes. The Location header points to the presentation API resource.

Bundle contents and limits

Include all dependencies in the ZIP. Empty code fences such as ```rust code/example.rs followed by a closing fence include the whole UTF-8 file; no line ranges or snippets are supported. Images and local links use paths such as images/diagram.svg and code/example.rs. An HTML embed uses:

:::iframe src="demo/index.html" title="Interactive demo"
:::

Local references must exist in the ZIP and are rewritten to immutable generation URLs. HTML can run sandboxed JavaScript, but all scripts, styles, images, fonts, and other resources must be bundled and use relative URLs. External resources and network APIs are blocked. Ordinary Markdown navigation links may still use HTTP(S), mailto, or fragments.

Limits: 20 MiB ZIP, 100 MiB extracted, 512 entries including directories, 2 MiB for root slides.md, and 4 MiB per HTML file. Only Stored and Deflated ZIP entries are supported. Symlinks, encrypted entries, duplicate paths, unsupported file extensions, and unsafe paths are rejected. Use ASCII letters, digits, dots, hyphens, and underscores in path segments; no spaces, absolute paths, or traversal.

Replace, then publish

Upload another complete ZIP to the same slug to replace the draft. Each upload installs a new immutable asset generation; replacement never changes published versions or their assets, including during live sessions. Uploading does not publish or start a session.

Bundle decks are read-only in the browser: preview, publish, present, and print are available. Existing legacy decks retain browser editing as a migration bridge. Publish and start sessions in the presenter UI.

JSON errors include a stable error.code and human-readable error.message.
