Endpoints

GET /api/v1/presentations
List presentations.
POST /api/v1/presentations
Create a presentation draft.
GET /api/v1/presentations/{slug}
Read a presentation and its Markdown source.
PATCH /api/v1/presentations/{slug}
Update its title, source, or theme. Slugs are immutable.
DELETE /api/v1/presentations/{slug}
Delete it unless a live session is active.
PUT /api/v1/embeds/{bundle}
Create or replace a local iframe bundle from a ZIP file.

{{ upload_embed_curl_example|safe }}

ZIP uploads are limited to 20 MiB compressed, 512 entries, 100 MiB extracted, and 4 MiB per HTML file. Bundles must contain an HTML file and cannot contain symbolic links or unsafe paths. Bundle names are global; replacements take effect immediately, so avoid replacing one during a live session.

JSON errors include a stable error.code and human-readable error.message.
