# Word-count slide examples

This directory contains the exact Python and Rust snippets shown in `examples/intro-to-rust.md`.

Run all checks from the repository root:

```sh
python3 code/word-count/verify.py
```

The verifier executes the working examples, checks the intentionally incomplete or non-compiling Rust steps for their expected failures, and confirms that the slide code fences still match the numbered source files exactly.
